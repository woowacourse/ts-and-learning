# 문제 11

## 막혔던 부분

```
declare가 뭔지 모름
외부 라이브러리를 사용하고 있는데, ts가 이 모듈들을 인식하게 해줘야함

그래서 declare module을 써서 ts가 이 친구의 존재를 알게 해야함
```

## 해결을 위해 필요한 키워드 1개

ts의 declare

## 키워드 단순 학습

외부 라이브러리를 사용하고 있는데, ts가 이 모듈들을 인식하게 만들어주기 위해 declare module을 사용한다.

## 문제에 적용시켜 해결한 방법

타입 별칭을 이용해서 string을 매개변수로 받아 string을 반환하는 타입을 만들고, export const 키워드를 사용해
5개의 유틸 함수 타입을 정의했다.

## 키워드 심화학습 (생각해볼만한 질문)

(Level 1 - 용어) const a: string = "hi"는 가능하지만, function a: string { ... }은 불가능합니다. 전자는 **'변수 선언'**이고 후자는 **'함수 선언'**입니다. 타입스크립트에서 : Type을 붙일 수 있는 대상은 보통 무엇인가요?

(Level 2 - 설명) export const strReverse: StrUtilType; 라고 쓰면 에러가 나지 않습니다. 왜 function 대신 const를 쓰면 학습자님이 만든 타입을 그대로 사용할 수 있을까요?

(Level 2 - 설명) declare module 내부에서 작성하는 코드는 실제 로직이 아니라 **'설계도'**입니다. 이 설계도 안에서 함수에 타입을 입히는 표준적인 방식(Standard Way) 2가지를 설명해 보시겠어요?

(Level 3 - 적용) 만약 function 키워드를 꼭 유지하고 싶다면, StrUtilType이라는 별칭을 쓰지 않고 어떻게 타입을 정의해야 할까요? (직접 코드를 적어보세요.)

(Level 4 - 변형/설계) 라이브러리를 만드는 입장이라면, export function 방식과 export const 방식 중 어떤 것이 사용자에게 더 명확한 정보를 줄까요? (가독성이나 호버 시 뜨는 정보 관점에서 생각해보세요.)
