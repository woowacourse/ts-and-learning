# ts-log: 학습 요약 생성 스킬

## 언제 사용하는가

`/ts-log`를 입력했을 때 실행됩니다.
현재 대화 또는 붙여넣은 내용을 분석해서 노션에 바로 복붙할 수 있는 형태로 정리합니다.

## 실행 절차

### Step 1: 내용 분석

대화에서 다음 다섯 가지를 추출합니다.

- **대화 요약**: 어떤 과정을 거쳐 질문이 나왔고, 어떤 시도를 했으며, 어떤 결론이 났는지의 흐름
- **막혔던 것**: 에러, 이해 안 됐던 개념, 풀지 못한 문제
- **막혔던 코드**: 막혔던 부분의 코드 스니펫 (있는 경우)
- **질문했던 것**: AI에게 물어본 것들
- **다음에 공부하면 좋을 것**: 대화 흐름상 이어서 보면 좋을 개념, 연관 키워드, 추천 학습 방향

### Step 2: 아래 형식으로 출력

````markdown
## 학습 요약 (MM/DD)

### 대화 요약

-

### 막혔던 것

-

### 막혔던 코드

```ts
// 코드가 없는 경우 이 섹션은 생략합니다
```

### 질문했던 것

-

### 다음에 공부하면 좋을 것

-
````

```

## 주의사항
- 대화에 없는 내용은 지어내지 않습니다.
- "대화 요약"은 티키타카 흐름을 간결하게 정리합니다. 길게 쓰지 않습니다.
- "막혔던 코드"는 대화에 코드가 있을 때만 포함합니다. 없으면 섹션 자체를 생략합니다.
- "다음에 공부하면 좋을 것"은 대화 맥락을 기반으로 추천합니다. 관련 없는 것은 넣지 않습니다.
- 노션에 바로 붙여넣을 수 있도록 마크다운 블록으로 출력합니다.
```
