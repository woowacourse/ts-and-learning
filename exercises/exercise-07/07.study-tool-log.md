문제 번호: [ #07 ]

1. 이 문제가 학습하길 의도하는 개념(내 추측)
[ generic ]
- 제네릭을 이용해서 매개변수의 타입을 받아서 
  특정 타입에 국한되지 않고 함수를 사용할 수 있게 한다
- Also this function shouldn’t necessarily be limited to just Person types, 
  lets type it so that it works with any two types specified.
  또한 이 함수는 꼭 Person 타입에만 제한될 필요는 없습니다.
  어떤 두 타입이든 동작할 수 있도록 타입을 정의해보세요.
- 이를 통해 swap 이라는 함수가 파라미터 두개를 바꾸는 범용적인 util 함수로 사용할 수 있게 됨 
2. 풀이 접근
[ generic ]
- generic
  - 타입을 이미 지정하지 않고 사용하는 시점에 원하는 타입을 정의해서 쓸수 있는 문법
  - 함수의 파라미터와 같은 역활
  - 역활: 함수의 인자를 넘긴 값을 함수의 파리미터로 받아 함수 내부에서 그대로 사용하는 방식을 의미

3. 실제 문제 의도 (ai)
[ generic, tuple ]
- 두 개의 서로 다른 타입을 유지하면서 순서를 뒤집는 것
- 타입을 잃지 않는 swap 함수 만들기
- 특정 타입에 종속되지 않게
- any: 타입 정보를 잃는다

4. 틀린 이유 (정리)
[ 여러 generic ]
- 테스트 통과는 되었으나 의도를 다 파악 못함
- 각 인자의 타입을 따로 보존해야 한다
- 반환 타입을 배열로 보는 사고 X -> T[] 는 의미적으로 순서 정보가 없다
  - tuple 개념 부제
  - tuple: 특정 형태를 갖는 배열, 배열 길이 고정, 각 요소 타입이 정의된 배열

5. 다음에 어떻게 할지
[ generics (multiple), tuple, type preservation, order-sensitive typing ]
- 타입이 여러개 나요면 generic도 여러개
- 순서가 중요하면 tuple
- 각 인자의 타입을 독립적으로 유지하면서 순서를 뒤집는다
- type preservation
  - 타입 보존
  - 타입 보존 실패 케이스: ```(number | string)[]```
- order-sensitive typing
  - 순서 민감 타입/순서를 반영하는 타입
