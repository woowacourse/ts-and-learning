3. 실제 문제 의도 (ai)
[ type predicate, Discriminated union ]
- 사용자 정의 함수에서도 타입 좁히기를 유지할 수 있는가?
- Discriminated Union 기반 narrowing은 된다
- 그런데 함수로 분리하면 깨진다

- Discriminated union을 함수로 분리했을 때도 타입 좁히기가 유지되도록 만들 수 있는가?
- type predicate
  - 타입 서술어/타입 술어
  - 사용자 정의 타압 가드
- Discriminated union
  - 구별된 유니언 타입
  - 유니언 타입을 구성하는 여러개의 타입을 
    특정 속성값 유무가 아니라
    특정 속성값으로 구분하는 타입 가드 문법
  - 모든 타입이 공통으로으로 가지고 있는 속성 + 그 속성값이 리터럴 타입으로 구정되어 있음
  - 그래서 이 type 으로 구별이 가능함
