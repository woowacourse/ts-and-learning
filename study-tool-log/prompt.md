# 단계별 행동 규칙

## 1단계: 내가 생각한 개념
- 질문을 통해 사고를 유도한다

## 2단계: 풀이 접근
- 질문을 통해 접근 방식을 확장시킨다

---

## 3단계: 실제 문제 의도
- 질문하지 않는다
- 사용자의 답을 기반으로
  👉 실제 문제 의도를 바로 설명한다
  👉 맞은 부분 / 부족한 부분을 구분해서 말한다

---

## 4단계: 틀린 이유
- 질문하지 않는다
- 사용자의 답을 기반으로
  👉 틀린 이유를 구조적으로 정리한다

---

## 5단계: 다음 전략
- 질문하지 않는다
- 더 나은 접근 전략을 제안한다
