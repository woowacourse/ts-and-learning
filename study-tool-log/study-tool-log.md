## 도구 1: study-log

**도구 유형**: Claude Code Skill

**해결하려는 문제**: 문제를 풀고 나서 매번 학습 로그를 수동으로 작성하는 것이 번거로웠다. 템플릿 형식을 기억해야 하고, 로그 번호를 확인하고, 이전 전략을 돌아보는 등 반복 작업이 많았다.

**어떻게 만들었는가**: `.claude/skills/study-log/SKILL.md` 파일에 학습 로그 작성 절차와 템플릿을 정의했다. 3문제를 풀 때마다 자동으로 트리거되거나, `/study-log`로 직접 호출할 수 있도록 설정했다. 로그 번호 자동 증가, 첫 번째/이후 로그 구분, AI 피드백 제공 등의 지침을 포함했다.

**어떻게 도움이 되었는가**: `/study-log`를 호출하면 AI가 필요한 항목을 하나씩 질문해주고, 답변을 기반으로 로그를 자동 작성해준다. 템플릿을 외울 필요 없이 대화하듯 로그를 남길 수 있어서 작성 부담이 줄었다. 또한 AI 피드백 섹션에서 학습 전략에 대한 구체적인 제안을 받을 수 있어 학습법 개선에 실질적으로 도움이 되었다.

## 도구 2: pr

**도구 유형**: Claude Code Skill

**해결하려는 문제**: PR을 생성할 때마다 base 저장소/브랜치 설정, PR 템플릿 작성, 리뷰 가이드라인 반영 등 반복적인 작업이 많았다. 특히 `gh pr create` 명령어에 올바른 `--repo`, `--base`, `--head` 옵션을 매번 기억하기 번거로웠다.

**어떻게 만들었는가**: `.claude/skills/pr/SKILL.md` 파일에 PR 생성 절차를 정의했다. upstream 저장소와 브랜치 설정, PR 템플릿(학습 목표, 체크리스트, 리뷰 요청), 리뷰 가이드라인(TS 지식/학습 과정/학습 도구 피드백)을 포함했다. `/pr`로 호출하면 push부터 PR 생성까지 한번에 처리되도록 했다.

**어떻게 도움이 되었는가**: `/pr` 한 번으로 push + PR 생성이 완료되어 명령어를 기억할 필요가 없어졌다. PR 템플릿이 자동으로 채워지므로 형식을 빠뜨리지 않고 일관된 PR을 작성할 수 있었다.
