# 학습 도구 로그

- 학습에 도움이 되는 도구를 만들고, 기록합니다. 필요하면 코드를 남깁니다.

## **도구 이름**
- TS 문제 추론 로그 (TS Inference Log)

## **도구 유형** (예: GPTs, gems, Claude Code(skill, command, agent, ...) Chrome Extension, CLI, 웹사이트 등)
- gpts 처럼 동작할 프롬프트 기반 학습 도구
  - 문제 풀이시 사고를 유도하는 코치 역활의 프롬프트
  - [prompt.md](./prompt.md)
- 문제별 사고 기록 템플릿
  - 문제 푸이 과정을 구조화 하여 기록
  - [template.md](./template.md)

## **해결하려는 문제**: 어떤 학습 상의 불편/문제를 해결하려 했는가?
- 문제를 풀이 중심으로 접근하게 됨
- 문제를 맞춰도 개념이 만지 않음
- 왜 틀렸는지 누적해서 파악하기 어려움
- gpt 사용시 사고 과정이 없이, 이해 없이 넘어감

## **어떻게 만들었는가**: 간단한 제작 과정
- 학습 과정을 문제 출제 의도를 먼저 추론해보고 풀 이후 실제 의도와 비교하는 방식으로 학습 과정을 구조화함
- 프롬프트 설계
  - gpt가 답을 주지 않고 사고를 유도하도록 역활을 제한함
  - 정답 제공을 막고 단계별 진행하도록 함
- 템플릿 설계
  - 문제마다 동일한 형식으로 개념 추론, 풀이 접근, 실제 의도, 틀린 이유, 다음 전략을 기록하도록 함

## **어떻게 도움이 되었는가**: 실제 사용 경험과 효과
