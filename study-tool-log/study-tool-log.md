# 학습 도구 로그

- 학습에 도움이 되는 도구를 만들고, 기록합니다. 필요하면 코드를 남깁니다.

## **도구 이름**

TS Learning Lab[https://gemini.google.com/share/8b64e64927d1]

## **도구 유형** (예: GPTs, gems, Claude Code(skill, command, agent, ...) Chrome Extension, CLI, 웹사이트 등)

Gemini Canvas 기반 웹사이트

## **해결하려는 문제**: 어떤 학습 상의 불편/문제를 해결하려 했는가?

- 에러메시지를 보자마자 검색이나 ai를 쓰면서 정답을 바로 묻는 습관을 줄이고 싶어서 만들게 되었다.
- 아래의 순서로 된 나만의 학습 사이클을 만들고 싶었다.
  - 왜 이런 문제가 발생했는지 먼저 스스로 생각해보기
  - 해결하기 위해서 키워드를 뽑아 학습하기
  - 문제 해결하기
  - 그 개념에서 확장해서 볼 수 있는 내용이 없는지 확인하기
  - 예제에 적용해보기

## **어떻게 만들었는가**: 간단한 제작 과정

Gemini Canvas를 이용해서 만들었고 초기 프롬프트는 아래와 같이 작성했다.

```
타입스크립트를 처음 배우는데 왜 에러가 발생했는지 먼저 예상해보고 에러를 해결해보면서 타입스크립트를 학습할 예정이야.

학습 사이클은 아래 순서로 구성할거야.
1. 문제 입력
2. 왜 에러가 났는지 가설 세워보기
3. 내 가설과 실제 근본적인 원인 비교해서 설명, 해결을 위한 학습 키워드 추천
4. 해결한 코드 제출
5. 맞는지 아닌지, 거기서 i+1 확장해서 생각해볼 개념 제시
6. 예제 적용하기
```

이후 실제로 사용해보면서 학습 키워드를 추천할 때 정답을 너무 직접적으로 알려준다거나, 마크다운 문법을 제대로 파싱하지 못하는 등 부족하다고 느껴지는 부분들을 계속 수정해나갔다.

## **어떻게 도움이 되었는가**: 실제 사용 경험과 효과

- 가장 도움이 되었던 점은 에러를 보고 바로 정답을 묻지 않고 왜 문제가 생겼을지를 스스로 생각해보게끔 하게 되었다.
- 생각만 하는게 아니라 적어보면서 타입스크립트를 잘 학습하고 있는지도 체크해볼 수 있었다.
- 지금 당장알아야할 핵심 개념과 확장해서 생각해볼 개념을 나누어 정리할 수 있어서 학습 범위가 너무 넓어지지 않도록 조절하기도 좋았다.
