# 학습 도구 로그

- 학습에 도움이 되는 도구를 만들고, 기록합니다. 필요하면 코드를 남깁니다.

---

## 도구 1

### **도구 이름**

ts-hint

### **도구 유형**

Claude Code 슬래시 커맨드 (`.claude/commands/ts-hint.md`)

### **해결하려는 문제**

AI에게 막히는 문제를 물어볼 때 정답을 바로 받아버리는 패턴이 반복되는 문제.
어느 단계에서 AI를 써야 하는지 기준이 없어서, 스스로 생각하기 전에 AI에 의존하게 됨.

### **어떻게 만들었는가**

1. PiFSR 5원칙과 3단계 개입 흐름(키워드 -> 접근방식 -> 피드백)을 프롬프트로 작성
2. 각 단계에서 코드 제공 금지 등 허용/금지 행동 명시
3. `.claude/commands/ts-hint.md`로 저장

```
.claude/commands/ts-hint.md -> /ts-hint 으로 호출
```

### **어떻게 도움이 되었는가**

- `/ts-hint exercise-03에서 막혔어` 처럼 호출하면 단계에 따라 힌트만 제공
- AI가 정답을 주는 패턴을 구조적으로 차단
- 스스로 먼저 시도하는 습관 형성에 도움

## 도구 2

### **도구 이름**

ts-log

### **도구 유형**

Claude Code Skill (`.claude/skills/ts-log/SKILL.md`) + 슬래시 커맨드 (`.claude/commands/ts-log.md`)

### **해결하려는 문제**

오늘 대화에서 막혔던 것, 질문했던 것을 따로 정리하지 않으면 기억이 흐릿해지는 문제.
노션에 기록하고 싶은데 형식에 맞춰 직접 쓰는 게 번거로움.

### **어떻게 만들었는가**

1. 대화 내용에서 막혔던 것 / 질문했던 것 / 다음에 공부하면 좋을 것을 추출하는 절차를 SKILL.md로 작성
2. 노션에 바로 복붙할 수 있는 마크다운 형식으로 출력하도록 설계
3. `.claude/commands/ts-log.md`에서 SKILL.md를 호출하도록 연결

```
.claude/
  commands/
    ts-log.md       -> /ts-log 으로 호출
  skills/
    ts-log/
      SKILL.md      -> 실제 정리 절차
```

출력 형식:

````markdown
## 학습 요약 (MM/DD)

### 대화 요약

-

### 막혔던 것

-

### 막혔던 코드

```ts
// 코드가 없는 경우 이 섹션은 생략합니다
```

### 질문했던 것

-

### 다음에 공부하면 좋을 것

-
````

### **어떻게 도움이 되었는가**

- `/ts-log` 한 번으로 오늘 대화 내용을 노션에 바로 붙여넣을 수 있는 형태로 정리
- 따로 기록하는 수고 없이 학습 흔적을 남길 수 있음
- 실제 사용 예시: [노션 학습 요약 페이지](https://respected-island-cf3.notion.site/by-Claude-Skill-32db1e15f1e980fd847af1d80ff07f38?source=copy_link)
