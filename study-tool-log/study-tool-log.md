# 학습 도구 로그

- 학습에 도움이 되는 도구를 만들고, 기록합니다. 필요하면 코드를 남깁니다.

## **도구 이름**

typescript exercises bot

## **도구 유형** (예: GPTs, gems, Claude Code(skill, command, agent, ...) Chrome Extension, CLI, 웹사이트 등)

gems

## **해결하려는 문제**: 어떤 학습 상의 불편/문제를 해결하려 했는가?

문제를 풀던 중 막혔을때 어떤 부분을 모르는지 알 수 없어 더 이상 학습을 진행할 수 없어서

## **어떻게 만들었는가**: 간단한 제작 과정

- Gemini에 요구 사항을 입력해 gems에 입력할 사전 프롬포트(요청 사항)를 대신 작성하도록 요청
- 생성된 사전 프롬포트를 gems 사전 프롬포트(요청 사항)에 입력

## **어떻게 도움이 되었는가**: 실제 사용 경험과 효과

문제 번호를 입력하면 문제에 대한 간략한 설명을 진행해주며, 작성중이던 코드를 입력하면 막힌 원인을 찾아주고 해결하기 위한 최소한의 힌트만 제공해 어떤 부분을 학습해야하는지 명확해짐
