## **도구 이름**

회고 생성기

## **도구 유형** (예: GPTs, gems, Claude Code(skill, command, agent, ...) Chrome Extension, CLI, 웹사이트 등)

Claude Code skill

## **해결하려는 문제**: 어떤 학습 상의 불편/문제를 해결하려 했는가?

회고하는 습관을 들이고 싶었지만, 막상 노션을 열면 무엇부터 써야 할지 막막했고 “오늘 무엇을 했지?”라는 생각이 자주 들었습니다.  
그래서 오늘 계획했던 것, 실패했다면 그 이유, AI와 나눈 대화 로그, 학습한 개념을 다시 리마인드할 수 있는 질문 형식, 그리고 내일 할 일과 오늘 고민했던 내용을 정리해주는 도구가 있으면 좋겠다고 생각했고, 그 아이디어를 바탕으로 만들었습니다.

## **어떻게 만들었는가**: 간단한 제작 과정

Claude에게 스킬을 만들자고 요청한 뒤, 원하는 목표를 설정했습니다.  
이후 부족한 부분은 질문을 통해 보완하고, 디테일한 부분은 직접 채워가며 완성했습니다.

## **어떻게 도움이 되었는가**: 실제 사용 경험과 효과

회고를 했다는 점에서 뿌듯함을 느꼈고, AI의 질문을 통해 내가 놓쳤던 부분이나 잘못 이해한 내용을 다시 점검할 수 있었습니다.  
또한, 다음 날 오전에 할 일을 미리 계획하면서 생각을 정리하는 데 도움이 되었습니다.

Claude Code skill

## **해결하려는 문제**: 어떤 학습 상의 불편/문제를 해결하려 했는가?

강의를 들으며 PiFSR를 적용하려 했지만 생각보다 쉽지 않았습니다.  
그래서 이 개념을 Claude에 적용해두고 AI에게 질문하면, 자연스럽게 한 단계씩 사고를 확장해 나갈 수 있지 않을까 하는 생각으로 만들게 되었습니다.

## **어떻게 만들었는가**: 간단한 제작 과정

Claude에게 스킬 제작을 요청한 뒤, PiFSR 개념을 포함하고 해당 방식대로 동작해달라고 설정했습니다.

## **어떻게 도움이 되었는가**: 실제 사용 경험과 효과

이전에는 질문 형식으로 답변해달라고 매번 요청해야 했지만, 스킬을 적용한 이후에는 자연스럽게 정답을 바로 알려주지 않고 의도를 드러내며 한 단계씩 사고를 확장해 나가는 느낌을 받았습니다.
