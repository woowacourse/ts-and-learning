---

## 도구 이름

`/map-my-gap`

## 도구 유형

Claude Code Skill

## 해결하려는 문제

"뭘 모르는지 모르는" 상태에서 오는 멘붕. 어디서 시작해야 할지 감이 잡히지 않을 때 의욕이 급격히 떨어지는 문제를 해결하려 했다.

## 어떻게 만들었는가

`~/.claude/skills/map-my-gap/SKILL.md` 파일을 작성해서 Claude Code 전역 스킬로 등록했다.
스킬 내부에 학습 원칙 5가지(Problem-Driven, i+1, Feedback Loop, Structural Thinking, Resourceful)와 실행 흐름을 정의했다.
Phase 1(WHY 연결) → Phase 2(개념 맵) → Phase 3(자가 진단) → Phase 4(출발점 하나) 순서로 동작한다.

## 어떻게 도움이 되었는가

항상 무엇을 찾아보고 물어봐야할지도 모르는 상태가 제일 답답하고 힘들었다.
질문을 통해 내가 정확히 무슨 개념이 모르는지를 파악한다.
크게 보면 가닥이 잡히지 않는 코드를 잘게 잘라서 제일 바닥부터 차근차근 관련 개념을 학습할 수 있도록 대화를 유도해준다.

## 도구 이름

`/stuck`

## 도구 유형

Claude Code Skill

## 해결하려는 문제

문제를 풀다가 막혔을 때 답을 바로 검색하거나 GPT에 물어보는 패턴을 끊고 싶었다. 답을 받는 게 아니라 스스로 깨달을 수 있도록 유도해주는 코치가 필요했다.

## 어떻게 만들었는가

`~/.claude/skills/stuck/SKILL.md` 파일을 작성해서 Claude Code 전역 스킬로 등록했다.
"답을 절대 알려주지 마라"를 절대 규칙으로 박아두고, 소크라테스식 질문 흐름으로 설계했다.
Step 1(Output First 확인) → Step 2(갭 진단) → Step 3(WHY 질문) → Step 4(소크라테스 질문) → Step 5(구조 시각화, 필요시) → Step 6(액션 하나) 순서로 동작한다.

## 어떻게 도움이 되었는가

무슨 결과값이 나올지 유추해보는 질문을 던져준다.
마치 TDD로 작은 범위부터 Test코드를 머릿속으로 짜보는 경험을 하게 해주어서 내가 막힌 이유를 통찰할 수 있게 해주었다.
모르는 개념이 있었다던지, 생각이 꼬였다던지, 놓치고 보지못한게 있었다던지 하는 부분을 캐치해주었다.
끝까지 정답을 직접적으로 알려주지 않고 질문을 통해 스스로 통찰 할 수 있게 해주었다.

## 도구 이름

`/retro`

## 도구 유형

Claude Code Skill

## 해결하려는 문제

문제를 풀고 나서 복습과 정리를 잘 못하는 성향 때문에 학습이 휘발되는 문제를 해결하려 했다. 매번 직접 회고를 작성하는 게 귀찮아서 안 하게 되는 걸 자동화하고 싶었다.

## 어떻게 만들었는가

`~/.claude/skills/retro/SKILL.md` 파일을 작성해서 Claude Code 전역 스킬로 등록했다.
명령어 호출 시점 이전 대화를 기준으로, 막혔던 포인트 / 고민한 것들 / 전환점이 된 힌트 / 지금 이해한 것 / 다음 i+1을 추출해서 노션에 바로 복붙할 수 있는 마크다운으로 출력한다.
출력 말투는 블로그 말투(반말, 구어체, 감정 솔직하게)로 고정했다.

## 어떻게 도움이 되었는가

나의 블로그, 자소서, 소감문 자료를 다 넘겨줘서 나의 말투나 성향을 파악토록 했다.
그렇다보니 나한테 익숙한 방식으로 정리를 잘 해주었다.
대화를 나누며 내가 어디서 막혔고 무슨 고민을 했는지를 알아서 정리해준다.
혼자 정리를 했다면 까먹을 법한 사세한 나의 고민조차도 기록이 되어있어서 학습 회고에 좋은 영향을 끼치는 것 같다.
