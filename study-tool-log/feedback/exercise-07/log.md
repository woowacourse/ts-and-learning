## 핵심 개념
- 제네릭 `<T, U>` — 두 타입 파라미터로 입력/출력 타입 연결
- 튜플 리턴 타입 `[U, T]` — 순서 반전을 타입으로 표현
- 불필요한 제약(`extends Object`) 제거

## Before
```ts
export function swap(v1, v2) {
    return [v2, v1];
}
```

## After
```ts
export function swap<T, U>(v1: T, v2: U): [U, T] {
  return [v2, v1];
}
```

## 시지프 피드백
- 제네릭 키워드는 스스로 떠올렸으나, `extends [User, Admin]` → `extends Object` → 제약 없음 순서로 좁혀나감
- 킹핀: 제네릭 타입 파라미터가 입력 타입을 캡처하고, 튜플 리턴 타입이 그 순서를 역전시킨다는 것
- i+1: 튜플 리턴의 각 원소 타입이 정확히 추론되는 이유 (타입 파라미터가 호출 시점에 바인딩됨)
