# TS와 학습법 튜닝하기

## 학습 목표

- TypeScript 기초 문법을 익힌다.
- 학습법 설계 → 시도 → 피드백 → … 루프를 반복하며, 학습법을 개선한다.

## 과제 요구사항
- [x] typescript-exercises 최소 12번까지 푼다.
  - 시간이 남는다면, 15번까지 도전해본다.
- [x] 자신이 설계한 학습과정을 적용해보고, 그것을 학습 로그(study-log)에 작성한다.
  - 최소 4회 이상 작성한다. 얼마의 시간 동안, 무엇을 학습했고, 어떤 학습 전략을 사용해서, 어떻게 학습했는지 의식적으로 돌아보고, 다음 타임에 어떻게 학습할지 계획을 세운다.
  - 12번까지 문제를 풀어야하니, 2~3문제 단위로 작성하는 것도 하나의 방법이다.
- [x] TypeScript 학습 또는 일반적인 학습에 도움이 되는 도구를 만들고, 학습도구 로그(study-tool-log)에 작성한다. 
  - 어떤 도구를 만들었고, 어떻게 도움을 받았는지 적는다. 스스로에게만 도움이 되면 된다. 도구는, 웹사이트, GPTs, gems, Claude Code(plugin, skill, agent), Chrome Extension, VS Code Extension, CLI, 봇 등 어떤 것이든 가능하다. 코드/프롬프트는 필요 시 올린다.
