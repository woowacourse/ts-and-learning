# TS와 학습법 튜닝하기

## 학습 목표

- TypeScript 기초 문법을 익힌다.
- 학습법 설계 → 시도 → 피드백 → … 루프를 반복하며, 학습법을 개선한다.

## 이번 미션에서 시도해볼 학습 방법

### 1. 목표 설정하기

오늘 몇 번 문제까지 해결할건지, 더 작게는 몇 시간 안에 몇 문제를 해결할건지 정확한 문제 수를 설정한다.

### 2. 일단 시도하기

아무것도 공부하지 않은 채로 이전에 타입스크립트 조금 학습한 경험을 되살려 최대한 문제를 해결한다.

### 3. 부족한 개념 학습하기

해당 문제에서 내가 모르면 절대로 풀 수 없는 핵심 개념 딱 1가지만 AI한테 알려달라고 한다.

해당 키워드만 공식 문서 또는 강의를 통해 학습한다.

### 4. 다시 시도하기

필요한 개념을 학습했으니 무조건 풀 수 있어야 한다.

만약 필요한 개념을 모두 알고 있음에도 문제를 해결하지 못했다면, 이전 학습을 잘못한 것이다.

잘못 학습한 개념이 무엇인지 확인하고 해당 개념이 사용된 문제로 돌아가 다시 풀고 정리한다.

### 5. 내 것으로 만들기

문제를 한 번 풀었다고 이해한 것이 아니다.

설정한 목표 문제들을 모두 해결했다면, 다시 빠르게 풀어본다.

낮은 수준의 문제이더라도 높은 단계를 해결하고 되돌아본다면 새롭게 느끼는 것이 분명 있을 것이다.

해당 문제에 주석으로 왜 이렇게 풀었는지, 다시 풀면서 새롭게 느낀점은 무엇인지 적어본다.
